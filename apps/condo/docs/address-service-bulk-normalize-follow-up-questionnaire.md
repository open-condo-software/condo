## Зафиксированное и больше не обсуждаемое в этой задаче

- Реализуется только новый метод в `apps/address-service`.
- Старые потребители, `/bulkSearch`, `PropertyResolver`, cottage village и qualityCheck сейчас не меняются.= bulkSearch вообще не менять и не планировать менять
- Helpers общие для пачки; `cities` удаляется; одна пачка относится к одной организации.
- Неизвестные поля отклоняются.
- `unitName` остается строкой, ведущие нули сохраняются, несколько перечисленных помещений считаются одним unit.
- Ошибки отдельных элементов отделяются от warnings; валидная пачка получает HTTP 200.
- Локализованные пользовательские тексты остаются у потребителей.
- В этом этапе не делаем shadow mode и не сравниваем результат со старыми нормализаторами.
