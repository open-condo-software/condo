# Address service: bulk normalization questionnaire

Статус: обсуждение контракта. Код не реализуем до согласования ответов.

Целевой сервис: `apps/address-service`.

Предполагаемый метод: `POST /bulkNormalize` для нормализации до 1000 адресов за запрос.

Как заполнять: под каждым вопросом заменить `Ответ:` своим ответом. Если подходит предложенный вариант, достаточно написать `Ответ: рекомендованный`.

## Выявленные особенности текущей реализации

- `/bulkSearch` принимает строки и возвращает объект `map`, поэтому одинаковые строки теряют индивидуальность.
- Внутренний размер пачки `/bulkSearch` сейчас равен 5.
- Текущий парсер может вернуть `unitType: flat` и `unitName: 1`, даже если помещение не указано.
- `PropertyResolver` отдельно проверяет ФИАС и текстовый адрес, после чего предпочитает дом, уже принадлежащий организации.
- Pullenti сейчас не сохраняет `Address` и может вернуть синтетический идентификатор `pullenti:...`.
- `qualityCheck` нужны причины расхождений, а не только нормализованный результат.
- Текущий ключ `AddressSource.source` зависит от `helpers` через их хеш.
