Помимо стандартных уведомлений вы можете показать пользователю уведомление со шкалой прогресса.
Данный метод создает уведомление с начальным нулевым прогрессом.

Данные уведомления хранятся в локальном хранилище пользователя, поэтому могут быть утрачены при смене браузера / сессии.
Уведомления также можно связать с вашим внешним процессом через параметр `externalTaskId` - ID вашей задачи,
которую описывает данное уведомление.

## Параметры метода

| Имя параметра  | Тип параметра                                     | Обязательный | Описание параметра                                                                                                                     |
|----------------|---------------------------------------------------|--------------|----------------------------------------------------------------------------------------------------------------------------------------|
| message        | string                                            | да           | Заголовок уведомления. Пример: "Загружаем данные"                                                                                      |
| description    | string                                            | нет          | Тело уведомления, в котором стоит описать дополнительную информацию. Пример: "Не закрывайте страницу"                                  |
| externalTaskId | string                                            | нет          | ID вашей задачи, которую отображает данное уведомление. Необходимо для синхронизации при выходе / входе пользователя в мини-приложение |
| processingFrame | `{ url }`                                        | нет          | Same-origin iframe-страница, которую Condo держит, пока progress bar активен или показывает действия.                                |
| actions        | `Array<{ label }>`                                | нет          | Действия мини-приложения. Требуют processing frame; Condo сам назначает ID и отправляет клики в этот iframe. Пока поддерживается одно действие. |

<Alert type='info'>
    Позже с помощью метода [CondoWebAppUpdateProgressBar](/docs/bridge/methods/notifications/update-progress-bar) можно обновить состояние и действия progress bar. `processingFrame` задаётся только при его создании.
</Alert>

## Возвращаемое значение

При успешном выполнении метод вернет ID созданной шкалы прогресса и назначенные Condo ID действий:
```json
{ "barId": "3f4714ab-30f9-4bd4-b91b-67e9c5b7f1a8", "actionIds": [] }
```

## Пример использования

```typescript
import bridge from '@open-condo/bridge'

bridge.send('CondoWebAppShowProgressBar', {
    message: 'Uploading some data',
    description: 'Please keep the page open',
    externalTaskId: '26abf417-9159-488d-a446-595e987d8802',
    processingFrame: { url: 'https://miniapp.example/import-progress?importId=123' },
}).then((data) => {
    console.log(data.barId)
})
```

![progress-bar-example](/bridge/show-progress-bar.png)

`processingFrame` доступен только iframe-странице того же origin. Он обязателен, если у progress bar есть действия. Condo хранит скрытый iframe, пока progress bar обрабатывается или показывает действия, и удаляет его после закрытия карточки задачи.

По клику на действие Condo отправляет `CondoWebAppActionClickEvent` с назначенным `actionId` в processing iframe. Мини-приложение само выбирает действие: например, вызывает `CondoWebAppShowModalWindow` или `CondoWebAppRedirect`.

При отмене progress bar Condo перед его удалением отправляет в processing iframe событие `CondoWebAppTaskCancelEvent`. В его данных есть host `taskId` и, если он был передан, `externalTaskId` мини-приложения. Мини-приложение само отменяет свою серверную работу.
