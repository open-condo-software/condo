This method allows you to update a previously created [progress bar notification](/docs/bridge/methods/notifications/show-progress-bar).

## Platforms
<SupportedPlatforms platforms={['B2BWeb']} />


## Method params

| Parameter name | Parameter type                                    | Required     | Parameter description                                                                                                                                                                                      |
|----------------|---------------------------------------------------|--------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| barId          | string                                            | yes          | Progress bar ID                                                                                                                                                                                            |
| data           | JSON                                              | yes          | Data to update: `message`, `description`, `progress`, `disableCancel`, `status`, or `action`. The background URL is set only when creating a bar. |

`data.progress` accepts a number from `0` to `100`. Set `data.status` to `completed` or `error` to finish the bar. A completed bar may include an action that opens a same-origin miniapp modal:

Use `{ type: 'link', label, url }` for a same-origin link or `{ type: 'modal', label, modal }` to open a modal.

```typescript
action: {
    type: 'modal',
    label: 'Details',
    modal: {
        title: 'Import details',
        url: 'https://miniapp.example/details',
        size: 'big',
    },
}
```

## Return value

If successful, the method will return a JSON object containing a single `updated` field:
```json
{ "updated": true }
```

## Usage example

```typescript
import bridge from '@open-condo/bridge'
// Update progress
bridge.send('CondoWebAppUpdateProgressBar', {
    barId: '3f4714ab-30f9-4bd4-b91b-67e9c5b7f1a8',
    data: {
        progress: 20,
        description: '5 seconds left'
    },
})

// Finish task
bridge.send('CondoWebAppUpdateProgressBar', {
    barId: '3f4714ab-30f9-4bd4-b91b-67e9c5b7f1a8',
    data: {
        progress: 100,
        description: 'done'
    },
})
```
