Данный метод позволяет обновить созданное ранее [уведомление со шкалой прогресса](/docs/bridge/methods/notifications/show-progress-bar).

## Платформы
<SupportedPlatforms platforms={['B2BWeb']} />


## Параметры метода

| Имя параметра  | Тип параметра                                     | Обязательный | Описание параметра                                                                                                                                                                                      |
|----------------|---------------------------------------------------|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| barId          | string                                            | да           | ID уведомления                                                                                                                                                                                          |
| data           | JSON                                              | да           | Данные для обновления: `message`, `description`, `progress`, `status` или `actions`. Processing frame задаётся только при создании progress bar. |

`data.progress` принимает число от `0` до `100`. Чтобы завершить процесс, передайте `data.status` со значением `completed` или `error`. Для действий progress bar должен быть создан с `processingFrame`:

```typescript
actions: [{ label: 'Подробнее' }]
```

Condo сам генерирует ID действий и возвращает их из метода. По клику Condo передаёт `CondoWebAppActionClickEvent` в processing iframe. Мини-приложение обрабатывает событие и решает, открыть ли modal, выполнить redirect или другой Bridge-метод.

```typescript
import bridge from '@open-condo/bridge'
import { useSetPageActionsHandlers } from '@open-condo/miniapp-utils'

const { actionIds } = await bridge.send('CondoWebAppUpdateProgressBar', {
    barId,
    data: { actions: [{ label: 'Подробнее' }] },
})

useSetPageActionsHandlers(bridge, {
    [actionIds[0]]: () => {
        void bridge.send('CondoWebAppShowModalWindow', {
            title: 'Детали импорта',
            url: 'https://miniapp.example/details',
            size: 'big',
        })
    },
})
```

## Возвращаемое значение

При успешном выполнении метод вернет `updated` и назначенные ID действий:
```json
{ "updated": true, "actionIds": [] }
```

## Пример использования

```typescript
import bridge from '@open-condo/bridge'
// Update progress
bridge.send('CondoWebAppUpdateProgressBar', {
    barId: '3f4714ab-30f9-4bd4-b91b-67e9c5b7f1a8',
    data: {
        progress: 20,
        description: '5 seconds left'
    },
})

// Finish task
bridge.send('CondoWebAppUpdateProgressBar', {
    barId: '3f4714ab-30f9-4bd4-b91b-67e9c5b7f1a8',
    data: {
        progress: 100,
        description: 'done'
    },
})
```
