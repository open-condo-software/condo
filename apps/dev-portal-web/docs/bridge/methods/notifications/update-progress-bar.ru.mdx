Данный метод позволяет обновить созданное ранее [уведомление со шкалой прогресса](/docs/bridge/methods/notifications/show-progress-bar).

## Платформы
<SupportedPlatforms platforms={['B2BWeb']} />


## Параметры метода

| Имя параметра  | Тип параметра                                     | Обязательный | Описание параметра                                                                                                                                                                                      |
|----------------|---------------------------------------------------|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| barId          | string                                            | да           | ID уведомления                                                                                                                                                                                          |
| data           | JSON                                              | да           | Данные для обновления: `message`, `description`, `progress`, `disableCancel`, `status` или `action`. URL фона задаётся только при создании progress bar. |

`data.progress` принимает число от `0` до `100`. Чтобы завершить процесс, передайте `data.status` со значением `completed` или `error`. Для действия progress bar должен быть создан с `background`:

```typescript
action: {
    label: 'Подробнее',
    actionId: 'open-import-details',
}
```

Condo передаёт клик как `CondoWebAppActionClickEvent` в background iframe. Мини-приложение обрабатывает событие и решает, открыть ли modal, выполнить redirect или другой Bridge-метод.

```typescript
import bridge from '@open-condo/bridge'
import { useSetPageActionsHandlers } from '@open-condo/miniapp-utils'

useSetPageActionsHandlers(bridge, {
    'open-import-details': () => {
        void bridge.send('CondoWebAppShowModalWindow', {
            title: 'Детали импорта',
            url: 'https://miniapp.example/details',
            size: 'big',
        })
    },
})
```

## Возвращаемое значение

При успешном выполнении метод вернет назад JSON-объект, содержащий единственное поле `updated`:
```json
{ "updated": true }
```

## Пример использования

```typescript
import bridge from '@open-condo/bridge'
// Update progress
bridge.send('CondoWebAppUpdateProgressBar', {
    barId: '3f4714ab-30f9-4bd4-b91b-67e9c5b7f1a8',
    data: {
        progress: 20,
        description: '5 seconds left'
    },
})

// Finish task
bridge.send('CondoWebAppUpdateProgressBar', {
    barId: '3f4714ab-30f9-4bd4-b91b-67e9c5b7f1a8',
    data: {
        progress: 100,
        description: 'done'
    },
})
```
