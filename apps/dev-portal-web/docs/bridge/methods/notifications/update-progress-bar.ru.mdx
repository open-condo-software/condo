Данный метод позволяет обновить созданное ранее [уведомление со шкалой прогресса](/docs/bridge/methods/notifications/show-progress-bar).

## Платформы
<SupportedPlatforms platforms={['B2BWeb']} />


## Параметры метода

| Имя параметра  | Тип параметра                                     | Обязательный | Описание параметра                                                                                                                                                                                      |
|----------------|---------------------------------------------------|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| barId          | string                                            | да           | ID уведомления                                                                                                                                                                                          |
| data           | JSON                                              | да           | Данные для обновления: `message`, `description`, `progress`, `disableCancel`, `status` или `action`. URL фона задаётся только при создании progress bar. |

`data.progress` принимает число от `0` до `100`. Чтобы завершить процесс, передайте `data.status` со значением `completed` или `error`. В завершённый progress bar можно добавить действие, открывающее same-origin modal мини-приложения:

Используйте `{ type: 'link', label, url }` для same-origin ссылки или `{ type: 'modal', label, modal }` для открытия modal.

```typescript
action: {
    type: 'modal',
    label: 'Подробнее',
    modal: {
        title: 'Детали импорта',
        url: 'https://miniapp.example/details',
        size: 'big',
    },
}
```

## Возвращаемое значение

При успешном выполнении метод вернет назад JSON-объект, содержащий единственное поле `updated`:
```json
{ "updated": true }
```

## Пример использования

```typescript
import bridge from '@open-condo/bridge'
// Update progress
bridge.send('CondoWebAppUpdateProgressBar', {
    barId: '3f4714ab-30f9-4bd4-b91b-67e9c5b7f1a8',
    data: {
        progress: 20,
        description: '5 seconds left'
    },
})

// Finish task
bridge.send('CondoWebAppUpdateProgressBar', {
    barId: '3f4714ab-30f9-4bd4-b91b-67e9c5b7f1a8',
    data: {
        progress: 100,
        description: 'done'
    },
})
```
