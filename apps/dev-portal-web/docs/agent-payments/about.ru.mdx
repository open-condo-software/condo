**Платежный шлюз** позволяет создавать ссылки на оплату и отслеживать оплату клиента и распределение средств.
Сервис рассчитывает комиссии и организует перечисление средств получателю по переданным реквизитам.

## Адреса API

Используйте базовый адрес нужной среды:

| Среда | Базовый адрес |
| --- | --- |
| Production | `https://rb.doma.ai` |
| Development | `https://rb.d.doma.ai` |

## Общая схема работы

1. Получите логин и пароль агента, назначенные имена мерчантов и тарифы.
2. Настройте [авторизацию серверных запросов](/docs/agent-payments/auth).
3. [Создайте платёж](/docs/agent-payments/create), передав реквизиты получателя и сумму в рублях.
4. Сохраните ответ вместе со своим `agentOrderId`, затем направьте клиента на `paymentUrl`.
5. [Проверяйте статус платежа](/docs/agent-payments/status) по полученному `id`.

## Суммы и комиссии

Все суммы в API — **десятичные строки в рублях**. Например, '123.45'.
Не добавляйте комиссии самостоятельно.

## Отчёты

После подтверждённого банком распределения сервис отправляет CSV-отчёты на согласованную почту.
Отчёты могут приходить частями и повторно; исключайте повторы по полю `id` записи отчёта.
Почта для отчётов настраивается при подключении.
